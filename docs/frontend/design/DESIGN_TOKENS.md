# デザイントークン定義書

## 1. カラーパレット

|------|-----|--------|
| Primary | `#2563eb` | ボタン、リンク、アクティブ状態 |
| Primary Hover | `#1d4ed8` | ホバー状態 |
| Primary Light | `#eff6ff` | 背景、バッジ |

## 2. タイポグラフィ

### フォントファミリー
- **本文**: system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
- **等幅**: ui-monospace, SFMono-Regular, 'Roboto Mono', monospace

### フォントサイズ・太さ
| 用途 | サイズ | 太さ | 行高 | 使用例 |
|------|--------|------|------|--------|
| ページタイトル | 2xl (24px) | bold (700) | 1.2 | ページ見出し |
| セクションタイトル | lg (18px) | semibold (600) | 1.4 | カード内セクション |
| ボディ | base (16px) | normal (400) | 1.5 | 本文、フォーム |
| 小さいテキスト | sm (14px) | medium (500) | 1.5 | 補足情報 |
| 最小テキスト | xs (12px) | medium (500) | 1.4 | ラベル、日付 |
| 等幅テキスト | xs (12px) | medium (500) | 1.4 | ID、金額 |

## 3. スペーシング（余白）

### スペーシングスケール
| トークン | 値 | 使用例 |
|----------|-----|--------|
| 1 | 4px | 微細な調整 |
| 2 | 8px | 要素間の最小余白 |
| 3 | 12px | アイコンとテキスト間 |
| 4 | 16px | カード内パディング |
| 5 | 20px | セクション間 |
| 6 | 24px | コンテナパディング |
| 8 | 32px | セクション区切り |
| 10 | 40px | 大きなブロック間 |
| 12 | 48px | ページ上下マージン |
| 16 | 64px | ヒーローセクション |

### レイアウト余白
- **ページパディング**: 24px (6)
- **カードパディング**: 20px (5) - 24px (6)
- **フォームフィールド間隔**: 16px (4)
- **グリッドギャップ**: 16px (4)
- **サイドバー幅**: 240px
- **ヘッダー高さ**: 56px

## 4. ボーダー・シャドウ

### ボーダー半径
| トークン | 値 | 使用例 |
|----------|-----|--------|
| sm | 4px | 小さなフィールド |
| md | 6px | 標準フィールド |
| lg | 8px | カード、ボタン |
| xl | 12px | 大きなカード |
| 2xl | 16px | モーダル |

### シャドウ

|----------|-----|--------|

| lg | 0 10px 15px rgba(0,0,0,0.1) | モーダル |

## 5. フォーカスリング

### 標準フォーカス
```css
box-shadow: 0 0 0 3px rgba(37, 99, 235, 0.1);
border-color: #2563eb;
```

### エラー時フォーカス
```css
box-shadow: 0 0 0 3px rgba(239, 68, 68, 0.12);
border-color: #ef4444;
```

## 6. トランスition

### 標準トランジション
- **期間**: 200ms
- **イージング**: ease-in-out
- **対象**: color, background-color, border-color, box-shadow, transform

## 9. コンポーネント別適用ルール

### ボタン
- **Primary**: bg-primary (`#2563eb`), text-white, px-6 py-2.5, rounded-lg, font-semibold
- **Secondary**: border-gray-200, text-gray-600, hover:bg-gray-50
- **サイズ**: sm (px-4 py-2), md (px-6 py-2.5), lg (px-8 py-3)

### 入力フィールド
- **高さ**: 42px (py-2.5 + テキスト)
- **パディング**: px-3 py-2.5
- **フォーカスリング**: 3px solid rgba(37, 99, 235, 0.1)

### カード
- **背景**: white
- **ボーダー**: 1px solid #e2e8f0
- **ボーダー半径**: 12px (xl)
- **パディング**: 20px - 24px

### バッジ・タグ
- **背景**: Primary Light (`#eff6ff`)
- **テキスト**: Primary (`#2563eb`)
- **パディング**: px-2.5 py-1
- **ボーダー半径**: full (9999px)
