# テーブル定義書

## `general.users` (ユーザーマスター)
### 概要
外部IdPで認証されたユーザーの、アプリケーション内におけるプロフィール情報を管理する。

### テーブル定義
| カラム名 | 論理名 | データ型 | 主キー | オプション | デフォルト | 説明 |
| :--- | :--- | :--- | :---: | :--- | :---  | :--- |
| `id` | ユーザーID | BIGINT | 〇 | GENERATED BY DEFAULT AS IDENTITY |  |アプリ内ユーザーID (自動採番) |
| `idp_subject` | IdPユーザーID | VARCHAR(255) |  | NOT NULL |  | 外部IdP側におけるユーザーの一意の識別子（OIDCの `sub` クレーム値） |
| `email` | メールアドレス | VARCHAR(255) |  | NOT NULL |  | メールアドレス |
| `name` | ユーザー名 | VARCHAR(100) |  | NOT NULL |  | ユーザー名 |
| `timezone` | タイムゾーン | VARCHAR(50) |  | NOT NULL | 'Asia/Tokyo' | ユーザーの優先タイムゾーン |
| `version` | バージョン | BIGINT | | NOT NULL | 0 | 楽観ロック用バージョンカウンター |
| `status` | ステータス | VARCHAR(50) |  | NOT NULL | 'ENABLED' | データの状態 ENABLED: 有効 DISABLED: 無効 DELETED: 削除 |
| `created_by` | 作成者 | BIGINT |  | NOT NULL | 0 | 作成者（ユーザーIDで、SQLで登録する場合は0） |
| `created_at` | 作成日時 | TIMESTAMP WITH TIME ZONE |  | NOT NULL | CURRENT_TIMESTAMP | 作成日時 (UTC) |
| `updated_by` | 更新者 | BIGINT |  | NOT NULL | 0 | 更新者（ユーザーIDで、SQLで更新する場合は0） |
| `updated_at` | 更新日時 | TIMESTAMP WITH TIME ZONE |  | NOT NULL | CURRENT_TIMESTAMP | 更新日時 (UTC) |

### 初期データ
ローカル環境では起動時に以下の検証用データを自動投入する。

| id | idp_subject | email | name | timezone | version | status |
| :--- | :--- | :--- | :--- | :--- |
| 1 | sso-user-uuid-0001 | admin@example.com | 管理者ユーザー | Asia/Tokyo | 0 | ENABLED |
| 2 | sso-user-uuid-0002 | user@example.com | 一般ユーザー | Asia/Tokyo | 0 | ENABLED |
