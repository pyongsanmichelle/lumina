# テーブル定義書

## `general.employee_departments` (従業員部署関連)

### 概要

従業員と部署の関連を管理する中間テーブル。兼務（1従業員が複数部署に所属）をサポートする。

### テーブル定義

| カラム名          | 論理名     | データ型                 | 主キー | オプション                       | デフォルト        | 説明                                                  |
| :---------------- | :--------- | :----------------------- | :----: | :------------------------------- | :---------------- | :---------------------------------------------------- |
| `id`              | 連番       | BIGINT                   |   〇   | GENERATED BY DEFAULT AS IDENTITY |                   | レコードを一意に識別する連番                          |
| `employee_number` | 従業員番号 | VARCHAR(50)              |        | NOT NULL                         |                   | 従業員の番号（employees.employee_numberへの外部キー） |
| `department_code` | 部署コード | VARCHAR(50)              |        | NOT NULL                         |                   | 部署のコード（departments.codeへの外部キー）          |
| `is_primary`      | 主務フラグ | BOOLEAN                  |        | NOT NULL                         | false             | 主として所属する部署かを示す                          |
| `version`         | バージョン | BIGINT                   |        | NOT NULL                         | 0                 | 楽観ロック用バージョンカウンター                      |
| `created_by`      | 作成者     | BIGINT                   |        | NOT NULL                         | 0                 | 作成者（ユーザーIDで、SQLで登録する場合は0）          |
| `created_at`      | 作成日時   | TIMESTAMP WITH TIME ZONE |        | NOT NULL                         | CURRENT_TIMESTAMP | 作成日時 (UTC)                                        |
| `updated_by`      | 更新者     | BIGINT                   |        | NOT NULL                         | 0                 | 更新者（ユーザーIDで、SQLで更新する場合は0）          |
| `updated_at`      | 更新日時   | TIMESTAMP WITH TIME ZONE |        | NOT NULL                         | CURRENT_TIMESTAMP | 更新日時 (UTC)                                        |

### 主キー

| 主キー名                |
| :---------------------- |
| pk_employee_departments |

### 外部キー

| 外部キー名             | カラム          | 参照テーブル        | 参照カラム      |
| :--------------------- | :-------------- | :------------------ | :-------------- |
| fk_emp_dept_employee   | employee_number | general.employees   | employee_number |
| fk_emp_dept_department | department_code | general.departments | code            |

### ユニークキー

| ユニークキー名       | カラム                            |
| :------------------- | :-------------------------------- |
| uk_emp_dept_emp_dept | employee_number + department_code |

### インデックス

| インデックス名          | カラム          |
| :---------------------- | :-------------- |
| idx_emp_dept_employee   | employee_number |
| idx_emp_dept_department | department_code |

開発環境では以下の検証用データを投入する。

| 1   | EMP001          | 02              |    true    | 0       | ENABLED |
| 2   | EMP002          | 02              |    true    | 0       | ENABLED |
| 3   | EMP002          | 03              |   false    | 0       | ENABLED |
