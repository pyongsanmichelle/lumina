# メッセージ（文言）管理・多言語化（i18n）定義書

本システムにおけるAPIレスポンスメッセージ、トースト通知、およびエラーメッセージの集中管理と多言語化に関する運用方針。

## 1. 基本方針
* バックエンドソースコード（Java）内へのメッセージ文字列のハードコーディングは禁止とする。
* すべての文言は、プロパティファイル（例: `messages_ja.properties`）にて集中管理する。
* クライアント（BFF）からの `Accept-Language` リクエストヘッダーに応じて、Spring Boot の i18n 機能により適切な言語メッセージを動的に返却する。

## 2. メッセージキー命名規則 (Naming Convention)
`messages.properties` に定義するキーは、競合を防ぎ検索性を高めるため、以下の階層構造で命名する。

> **`[種類].[ドメイン/機能].[項目名（任意）].[識別子]`**

| 種類 (`[種類]`) | 用途 | キーの例 |
| :--- | :--- | :--- |
| `info` | 正常系のトースト通知や案内 | `info.user.create.success` (ユーザー登録が完了しました。) |
| `error` | 業務エラーやシステムエラー | `error.user.status.disabled` (無効化されたユーザーは編集できません。) |
| `valid` | 単項目・相関バリデーションチェック | `valid.user.email.required` (メールアドレスは必須入力です。) |
